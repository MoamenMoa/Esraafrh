# إشراف — نظام إدارة مشاريع التشطيبات

نسخة تشغيل فعلية متجاوبة للموبايل والكمبيوتر، مبنية كواجهة Static قابلة للنشر على GitHub Pages، مع Firebase Authentication وCloud Firestore لحفظ ومزامنة البيانات بين الأجهزة.

## المزايا المنفذة

- دخول منفصل للمدير `Esraafrh` والمستخدمين `Mohamed Elnshwi` و`AhmedNagib`.
- المدير ينشئ مشروعًا فيظهر فورًا لكل المستخدمين.
- المشروع يمكن أن يكون متاحًا لكل الفريق أو معينًا إلى مستخدم محدد.
- أول مستخدم يضغط **✓ ابدأ العمل** يتم تسجيل اسمه وتوقيت البداية ولا يستطيع مستخدم آخر استلام المشروع.
- قائمة تحقق مقسمة إلى مراحل، مع علامة صح لكل بند وتسجيل اسم وتوقيت من أنهى البند.
- إضافة ملاحظة لكل بند من قائمة التحقق.
- ملاحظات عامة ومشكلات للمشروع، ولكل ملاحظة علامة صح عند إغلاقها.
- حساب نسبة الإنجاز تلقائيًا من عدد بنود قائمة التحقق المكتملة.
- رفع عناصر قائمة التحقق من Excel أو CSV مع معاينة ومنع التكرار.
- مصروفات المشروع: البيان، التصنيف، المبلغ، التاريخ، المورد، رقم الفاتورة والملاحظات.
- رفع صورة الفاتورة وعرضها وتحميلها لاحقًا.
- تصدير تقرير المشروع إلى Excel وطباعة تقرير PDF من المتصفح.
- سجل نشاط يوضح من بدأ العمل ومن أضاف أو أنهى أو حذف.
- لوحة رئيسية وإحصائيات وإجمالي مصروفات كل المشاريع.
- تصميم RTL عربي متجاوب للموبايل والتابلت والكمبيوتر.
- لا يوجد وضع تجربة ولا تخزين محلي للبيانات.

## بدء التشغيل

ابدأ بالملف:

1. `START_HERE_AR.md`
2. ثم `SETUP_FIREBASE_AR.md`
3. ثم `DEPLOY_GITHUB_AR.md`

## الملفات المهمة

- `index.html` — واجهة الموقع.
- `styles.css` — التصميم المتجاوب.
- `app.js` — وظائف النظام والاتصال بـFirebase.
- `firebase-config.js` — ضع داخله بيانات Firebase Web App.
- `firestore.rules` — صلاحيات قاعدة البيانات.
- `firestore.indexes.json` — تعطيل فهرسة بيانات صورة الفاتورة الكبيرة.
- `seed-data.js` — مشروع هليوبوليس وعناصره.
- `checklist-template.xlsx` — نموذج Excel جاهز.
- `checklist-template.csv` — نموذج CSV.

## ملاحظة صور الفواتير

صورة الفاتورة تُضغط في المتصفح وتُحفظ داخل Firestore في مستند منفصل. الصيغ المقبولة: JPG وPNG وWEBP، والحد الأقصى للصورة الأصلية 12 MB. لا يحتاج هذا التنفيذ إلى Firebase Storage.
